# Emotion Model

- `emotion_model.pkl`
  مودل المشاعر الجاهز للتشغيل.

- `emotion_label_encoder.pkl`
  محول الفئات النصية والرقمية الخاص بالمودل.

- `emotion_labels.json`
  خريطة الفئات النهائية التي يرجعها المودل.

- `emotion_test_split.npz`
  تقسيمة الاختبار المحفوظة لاستخدامها أثناء التقييم.

- `emotion_training_report.json`
  تقرير نتائج التدريب والدقة.

- `vectors/`
  ملفات `X.npy` و `y.npy` وخرائط الـ labels المستخدمة في التدريب.
